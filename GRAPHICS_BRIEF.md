# Aurelon — Complete Graphics Brief

All images for the Aurelon landing page. The visual language follows **Apple's product page philosophy**: obsessive restraint, dramatic lighting, hero-centric compositions, and lifestyle imagery that feels like a still from a film — never a stock photo. Every image should make the viewer feel something before they understand what the product does.

---

## Visual Direction: The Apple Standard

### Core Principles
1. **The product is the hero.** In product shots, nothing competes with the glasses. No props, no distractions. Just the object, light, and shadow.
2. **Lifestyle = cinema.** Every lifestyle image should feel like a single frame pulled from an award-winning film. Candid, emotional, beautifully lit. Never posed, never stock.
3. **Light tells the story.** Apple uses light as a narrative tool — a single key light sculpting form, ambient glow creating mood. We do the same. Golden hour for warmth. Studio rim-light for drama.
4. **Negative space is content.** Let images breathe. A product floating in clean space is more premium than a product surrounded by "premium" props.
5. **Colour restraint.** 2-3 dominant tones per image. No rainbow. Our palette: black, cream, gold, warm skin tones. That's it.

### Reference Boards
- apple.com/airpods-pro (product hero shots, dark bg, dramatic lighting)
- apple.com/apple-vision-pro (lifestyle shots, cinematic grain, emotional moments)
- apple.com/iphone (clean product gallery, every angle matters)
- Aesop.com (warm editorial lifestyle, muted palettes)
- Nothing Phone product page (dark dramatic hero, clean type)

## Generation Guidelines

### The Apple Test
Before finalising any image, ask: "Would Apple put this on their homepage?" If no — reshoot. Apple's bar is:
- **Product shots:** Nothing in the frame that isn't the product. Light as a design element.
- **Lifestyle shots:** The person looks like they belong in a film, not an ad. The technology is invisible. The emotion is real.
- **Composition:** Intentional negative space. Nothing accidental. Rule of thirds or dead center — no in-between.
- **Colour:** Restrained. 2-3 tones max. Warm, never garish.

### Style Consistency
- All lifestyle images (solutions, video poster) should feel like they're from the same cinematographer's reel — same warm colour grade, same Kodak film grain character, same anamorphic depth of field
- All product images should feel like the same studio session — same single key light, same background, same floating-with-shadow treatment
- The overall aesthetic DNA: **Apple (product precision) + Aesop (warm restraint) + Mykita (eyewear authority)**

### Technical Requirements
- Format: `.webp` for all raster images (best compression for web)
- Quality: 85% for lifestyle photos, 90% for product shots
- Max file size: 200KB for lifestyle images, 150KB for product shots
- Always provide `@2x` versions (double the listed dimensions) for Retina displays, then compress to listed dimensions for `src`
- sRGB colour space for all web images

### AI Generation Tool Notes
- **Midjourney:** Use `--ar 1:1` or `--ar 4:3`, `--style raw` for less stylised results, `--v 6.1`, add `--no text logo watermark` to every prompt
- **DALL-E 3:** Specify exact dimensions, use "photorealistic editorial Apple product page quality" in prompt
- **Stable Diffusion:** Use realistic models (SDXL Realistic, JuggernautXL), CFG 5-7, sampler DPM++ 2M Karras, 30-40 steps, add quality embedding
- **Flux:** Use `[img2img]` with reference product photos for consistency, Flux Pro for highest quality

### Colour Grading Reference (Lifestyle Images)
Apply in post-processing for the Apple cinematic feel:
- Shadows: warm (+5 orange), slightly lifted (no true blacks — Apple never uses pure black in lifestyle)
- Highlights: slightly gold (+3 yellow), gently rolled off (no clipped whites)
- Midtones: neutral to warm, clean skin tones
- Film grain: subtle, Kodak Portra character — ~15% at 50% size
- Vignette: very light, 10-15%, optical not artificial
- Contrast: medium — lifted blacks give that premium film look
- Saturation: slightly desaturated overall, then push gold/amber channel +10%
- White balance: 5800K-6200K (warm daylight, never cool)

### Product Shot Lighting Reference
For the Apple studio look:
- Single key light: large softbox from top-left, 45-degree angle
- Fill: very subtle — let shadows exist but stay open
- Background: pure cream (#FAF8F5), lit evenly, no gradients
- Shadow: contact shadow only — soft, tight, directly below product
- No rim light on product shots (save that drama for the OG image)
- Highlight on top edge of frame should be the brightest element
