## Generation Guidelines

### Style Consistency
- All lifestyle images (solutions, video poster) should feel like they're from the same editorial photoshoot — same warm colour grade, same 35mm film grain, same depth of field style
- All product images should feel like the same studio session — same lighting rig, same background colour, same shadow style
- The overall aesthetic is: **Aesop meets Apple meets Mykita** — warm, minimal, premium, quiet

### Technical Requirements
- Format: `.webp` for all raster images (best compression for web)
- Quality: 85% for photos, 90% for product shots
- Max file size: 200KB for lifestyle images, 150KB for product shots
- Always provide `@2x` versions (double the listed dimensions) for retina displays, then compress down to the listed dimensions for the `src` attribute

### Aspect Ratios Summary
| Image Type     | Ratio  | Dimensions   |
|----------------|--------|--------------|
| Product shots  | 1:1    | 1200 x 1200  |
| Solution shots | 4:3    | 1200 x 900   |
| OG image       | 1.91:1 | 1200 x 630   |
| Logo           | 1:1    | 32 x 32      |
| Favicon        | 1:1    | 32 x 32      |

### AI Generation Tool Notes
- **Midjourney:** Use `--ar 1:1` or `--ar 4:3`, `--style raw` for less stylised results, `--v 6.1`
- **DALL-E 3:** Specify exact dimensions in prompt, use "photorealistic editorial" in prompt
- **Stable Diffusion:** Use realistic models (SDXL Realistic, JuggernautXL), CFG 5-7, sampler DPM++ 2M Karras, 30-40 steps
- **Flux:** Use `[img2img]` with reference product photos for consistency

### Colour Grading Reference
For lifestyle images, apply in post-processing:
- Shadows: warm (+5 orange)
- Highlights: slightly gold (+3 yellow)
- Midtones: neutral to warm
- Film grain: subtle, ~15% at 50% size
- Vignette: very light, 10-15%
- Contrast: slightly lifted blacks (matte film look)
